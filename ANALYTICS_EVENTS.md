# Mapa futuro de eventos

No se ha instalado ninguna herramienta de analítica. Estos eventos quedan definidos para una implementación posterior autorizada.

| Evento | Disparador | Parámetros sugeridos |
|---|---|---|
| `project_open` | Apertura de caso | proyecto, origen, posición |
| `project_filter` | Uso de filtro | filtro, resultados |
| `service_open` | Apertura de acordeón | servicio, página |
| `showreel_open` | Apertura de showreel | página |
| `form_start` | Primer avance del formulario | origen |
| `form_step` | Cambio de etapa | número, nombre |
| `form_complete` | Envío exitoso | servicios, sector |
| `cta_click` | Clic en CTA | etiqueta, ubicación |
| `scroll_depth` | Profundidad | 25, 50, 75, 100 |
